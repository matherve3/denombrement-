🔹 1. Permutations & factorielle ▶

Définition : Une permutation d'un ensemble à $n$ éléments est un arrangement ordonné de ces $n$ éléments. Le nombre de permutations est $n! = n \times (n-1) \times \cdots \times 1$.

📌 Propriétés

$0! = 1$, $1! = 1$.

Nombre de façons de classer $n$ objets distincts : $n!$.

🔹 2. Arrangements ▶

Définition : Un arrangement est une sélection ordonnée de $k$ éléments parmi $n$ ($k \le n$), sans répétition.

📐 Formule

$A_n^k = n \times (n-1) \times \cdots \times (n-k+1) = \frac{n!}{(n-k)!}$.

Exemple : le nombre de tiercés possibles avec 20 chevaux (ordre important, sans ex-aequo) est $A_{20}^3 = 20 \times 19 \times 18 = 6840$.

🔹 3. Combinaisons & binôme ▶

Définition : Une combinaison est un choix non ordonné de $k$ éléments parmi $n$.

📌 Coefficient binomial

$\binom{n}{k} = \frac{n!}{k!(n-k)!} = \frac{A_n^k}{k!}$.

Symétrie : $\binom{n}{k} = \binom{n}{n-k}$.

Formule du binôme : $(a+b)^n = \sum_{k=0}^n \binom{n}{k} a^k b^{n-k}$.

Triangle de Pascal : $\binom{n}{k} + \binom{n}{k+1} = \binom{n+1}{k+1}$.

🔹 4. Dénombrement & Probabilités ▶

Principe : Dans un univers équiprobable, $P(A) = \frac{\text{nombre de cas favorables}}{\text{nombre de cas possibles}}$.

📐 Exemples

• Lancer de deux dés : 36 issues, probabilité d'un double = $\frac{6}{36} = \frac{1}{6}$.

• Tirage sans remise de 2 cartes dans un jeu de 32 : nombre de mains = $\binom{32}{2} = 496$.
